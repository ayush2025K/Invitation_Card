# Shreyas Birthday Invitation

This repository contains a single-file interactive birthday invitation (`invitation.html`) with animations, sparkles, confetti, music toggle, a countdown, and placeholder images. Drop in your own photos (replace `photo1.svg` etc. or change the image paths) and a `music.mp3` file if you want background music.

How to preview

1. Open `invitation.html` in a browser (double-click or use `open` on macOS):

   open "invitation.html"

2. Replace the `photo*.svg` placeholders with your own photos or change the `img` srcs in the HTML.

Notes
- If you add `music.mp3` to the project root the music toggle will work.
- The page is self-contained; you can host it via GitHub Pages by pushing this repository and enabling Pages in repo settings.
